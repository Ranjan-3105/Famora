# FAMORA - The Family Salon

A premium luxury family salon single-page application built with Next.js (App Router), React, and Vanilla CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Next.js App Router**: Fast, optimized, and SEO friendly.
- **Responsive Design**: Built mobile-first with a custom Vanilla CSS design system.
- **Premium UI**: Custom color palettes, subtle animations, and high-quality placeholders.
- **Semantic HTML**: Fully accessible layout structure.
